# WPS Project Management PRD Template

Use this template to produce a WPS-specific PRD.

## Template
```markdown
# [Feature / Initiative Name] PRD

## 1. Executive Summary
- Problem
- Solution
- Expected impact

## 2. Edition and Scenario Context
- Edition:
- Primary role:
- Collaborating roles:
- Core scenario:
- Out-of-scenario boundary:

## 3. Problem Statement
- Who has the problem
- What breaks today
- Why it matters now
- Evidence

## 4. Strategic Context
- Strategic fit
- Related product goals
- Why now

## 5. Solution Overview
- Summary
- Main flow
- Key user actions

## 6. Roles, Permissions, and Object Model
- Roles involved
- Permission rules
- Affected objects
- State transitions

## 7. WPS Integration Points
- Document / meeting / IM / calendar / org integration impact

## 8. Requirements
- User stories
- Acceptance logic
- Edge cases

## 9. Metrics and Instrumentation
- Primary metric
- Guardrail metrics
- Events to track

## 10. Dependencies, Risks, and Rollout
- Dependencies
- Risks
- Rollout plan

## 11. Out of Scope
- What is excluded

## 12. Open Questions
- Question 1
- Question 2
```
