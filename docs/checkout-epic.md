# Checkout Epic：结账流程优化

## 用户故事 US-CHK-001

- **Summary:** 支持游客一页式结账以降低购买流失

#### Use Case:
- **As a** 首次访问的电商游客用户
- **I want to** 在同一页面完成收货信息、配送方式与支付信息填写并提交订单
- **so that** 我可以更快完成下单、避免因流程过长而中途放弃购买

#### Acceptance Criteria:

- **Scenario:** 游客用户在购物车后进入一页式结账并成功下单
- **Given:** 我已将至少 1 件可售商品加入购物车
- **and Given:** 我未登录账号（以游客身份下单）
- **and Given:** 我在结账页面可以看到「收货地址」「配送方式」「支付信息」「订单总览」四个区块
- **and Given:** 订单总览会实时展示商品小计、运费、税费（如适用）与应付总额
- **When:** 我在该页面完成必填信息并点击「提交订单」
- **Then:** 系统创建订单成功并展示包含订单号的确认页面，同时发送下单成功通知（页面提示或邮件）
